# On the Record (STT 회의록 Obsidian 플러그인)

Obsidian 데스크톱용 커뮤니티 플러그인 프로젝트이다. 플러그인 id는 `on-the-record`이다. 녹음 오디오를 로컬에서 전사하고, 전사 결과를 검토한 뒤 노트에 반영한다.

## 현재 상태

초기 구현 단계이다. 설정 화면과 vault/PC별 설정 저장, 녹음 감지 및 파일 찾기에서 오디오를 검증해 메모리 대기열에 넣는 기능, provider 공통 타입 계약을 구현했으며 녹음 감지와 파일 찾기의 기본 수동 시험을 마쳤다. 실제 provider 엔진 실행, 결과 미리보기·노트 반영은 아직 구현되지 않았다. 단계별 구현과 시험 결과는 [CHANGELOG.md](./CHANGELOG.md)와 [TODO.md](./TODO.md)에 기록한다.

## 개요

- Obsidian 코어 Audio recorder가 만든 녹음 파일, 또는 사용자가 선택한 오디오 파일을 전사한다.
- 전사는 사용자 PC에서 `whisper.cpp`로 실행한다. 오디오와 노트 내용을 외부로 전송하지 않는다.
- 전사 결과는 사용자가 검토하고 승인한 뒤 노트에 삽입한다.
- 지원 대상은 Obsidian Desktop(Windows x64)이다. 모바일, macOS, Linux는 지원하지 않는다.
- 사용자가 별도로 설치한 전사 엔진과 모델은 vault 밖의 사용자별 디렉터리에 둔다. 플러그인은 런타임이나 모델을 다운로드·설치·업데이트·삭제하지 않는다.

## 단계별 개발 기능

각 단계의 상세 내용은 [개발계획서](./docs/design/STT_회의록_커뮤니티플러그인_개발계획서.md)를 따른다. 단계별 작업 항목은 [TODO.md](./TODO.md)에 기록한다.

| 단계 | 개발 기능 |
|---|---|
| 0. 기준선 | 오디오 입력 형식 표본 수집, `whisper.cpp` CPU 전사의 처리 속도·메모리 측정, Obsidian 공개 API로 녹음 산출물을 감지할 수 있는지 검증 |
| 1. 공통 파이프라인 | 설정 화면 및 저장, 녹음 파일 감지·안정화·노트 링크 확인과 파일 찾기 기능(기본 수동 시험 완료), 메모리 대기열, provider 계약, 결과 미리보기 |
| 2. CPU 전사 | 사용자가 준비한 `whisper.cpp` CPU 런타임·모델 탐지·검증, 오디오 변환, 자동 전사 시작, segment timestamp 출력, 전사문 검색 |
| 3. GPU 검증 | NVIDIA CUDA, Intel GPU provider의 속도·메모리 측정. 측정 결과로 배포 여부 결정 |
| 4. 분석 기능 검증 | 단어 정렬, 고유명사 후보 추출, 화자 분리, 환경음 분석을 각각 별도로 평가 |
| 5. 분석 기능 통합 | 4단계에서 검증된 기능만 통합 |
| 6. 프로필 확장 | 회의 유형별 프로필, 용어집, 노트 템플릿 |

## 지원 입력 형식

`.m4a`, `.mp3`, `.wav`, `.aac`, `.ogg`. 파일 시그니처와 코덱을 검사하고, 지원하지 않는 파일은 사유를 표시한다.

## 범위 밖

- 오디오 녹음 기능 구현
- 클라우드 전사, 외부 API 업로드
- 전사 직후 노트 자동 덮어쓰기
- 화자 실명 확정, 음향 기반 장소·상황 판정

## 개발 환경

- 작업 폴더(개발자 개인 환경): OneDrive `STT` 폴더. 개발자의 여러 PC에서 동기화하며 한 번에 한 PC에서만 작업한다. 사용자에게 요구하는 환경이 아니다.
- 시험 환경: 개발 PC 2대(Windows 11 x64). CPU, 내장 GPU, NVIDIA GPU 구성이 서로 다르다. 사양은 [Samsung](./benchmarks/hardware/systeminfo_Samsung_960XFG.md), [Lenovo](./benchmarks/hardware/systeminfo_Lenovo_IdeaPad_Gaming3.md) 문서에 있다.
- 시험 볼트(개발자 개인 환경): 업무용 볼트와 분리한 `PlugVaults` 볼트에 배포해 시험한다.
- 이 플러그인은 사용자가 vault를 어떤 방식으로 동기화하는지(동기화 서비스 종류, 동기화 여부)를 가정하지 않는다.

## 소유·관리

- 저작권자는 `에스넷시스템`이며, 권리 귀속 및 공개 승인이 확인되었다(2026-11-05 사용자 확인).
- 현재 GitHub 저장소는 개발자 개인 계정에서 관리한다. 회사 공식 GitHub 저장소가 확정되면 이관한다.
- 공개 권한 및 Obsidian 디렉터리 정책 검토는 확인됐다. 실제 배포 구성요소의 라이선스 검토가 남아 있어 공개·배포를 보류한다.

MIT 표기는 외부 라이브러리, 실행 파일, 모델 가중치, 데이터 및 기타 제3자 자료에 자동 적용되지 않는다. 실제 배포에 포함하거나 사용자가 별도로 취득하도록 안내할 각 구성 요소는 정확한 버전·출처·라이선스·고지 및 재배포 의무를 개별 확인한 뒤 배포 또는 안내한다. 자세한 기준은 [개발계획서](./docs/design/STT_회의록_커뮤니티플러그인_개발계획서.md)와 [라이선스 정책 보고서](./docs/research/STT_라이선스정책_에스넷그룹_명세_및_체계검토.md)를 참조한다.

## 네트워크 및 vault 밖 파일

플러그인 자체는 오디오·노트·모델을 네트워크로 전송하지 않으며, 원격 서비스나 텔레메트리를 사용하지 않는다. 사용자는 별도로 전사 엔진과 모델을 받아 설치·업데이트해야 한다. 이 파일들은 크기가 크고 실행 파일이므로 vault에 포함하지 않고 사용자 로컬 데이터 폴더에 보관한다. 플러그인은 사용자가 지정한 해당 로컬 경로의 엔진·모델을 확인하고 실행한다. Obsidian 코어 녹음과 전사 입력 오디오는 vault 안에서 읽으며, vault 밖 오디오 입력은 현재 계획 범위에 포함하지 않는다.
