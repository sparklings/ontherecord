# 0-BASE-02 한국어 회의 샘플 출처 및 무결성 기록

- **기록일:** 2026-11-02
- **상태:** 한국어 회의 오디오 3개 확보, 출처와 SHA-256 기록 완료.
- **언어·내용 확인 근거:** 사용자가 기존에 확보한 세 오디오가 모두 한국어 회의 샘플임을 확인했다. 기록자는 오디오를 재생하거나 전사하지 않았다.

## 출처와 보관

원본은 사용자가 지정한 Obsidian vault의 첨부 파일에서 선택한 M4A 녹음이다. 원본 파일명과 vault의 절대 경로는 개인정보와 회의 식별정보 보호를 위해 문서화하지 않았다. 파일은 `samples\real-audio\`에 익명 ID로 보관하며, 해당 폴더 전체는 `.gitignore`로 Git에서 제외한다.

선택 기준은 `0-BASE-01`에서 기술 표본으로 확보한 3개 녹음의 길이 구간(짧음·중간·김)이다. 원본은 모두 MP4/M4A 컨테이너 안에 Opus 오디오를 담고 있으며, 48 kHz 모노로 확인됐다. 오디오 내용은 전사하거나 분석하지 않았다.

SHA-256은 로컬 표본 파일에서 계산했으며, 원본 복사본의 해시가 선택된 첨부 파일의 해시와 일치함을 확인했다. 파일 메타데이터와 변환본의 세부 해시는 [0-BASE-01 표본 기록](./BASE-01_AUDIO_FORMAT_FIXTURES_2026-11-02.md)을 참조한다.

## Git 보안 확인

- `.gitignore`의 `/samples/` 규칙은 오디오뿐 아니라 표본 폴더의 모든 파일(향후 전사문·라벨 포함)을 제외한다.
- 확인 시 `samples/` 아래 표본 파일은 모두 Git ignored 상태였고, 이미 Git 추적 중인 샘플 파일은 없었다.
- `.gitignore`는 Git 커밋·push만 통제한다. 저장소가 OneDrive 동기화 위치에 있으므로 OneDrive 동기화까지 차단하는 설정은 아니다.

## 평가 사용 시 주의

이 오디오 세트는 실제 회의 음성을 포함한다. 모델 정확도 평가용 기준 전사본(CER 등)을 만들거나 공유하기 전, 녹음 참여자의 동의와 조직의 녹음·보관 정책을 확인해야 한다. 이 기록에는 전사 내용, 발화자, 회의 주제 또는 파일명을 포함하지 않았다.
