- 속도 순서는 샘플 01·02와 같다(base < small < medium < turbo < large-v3). medium만 오디오보다 빠르게(1시간 오디오 약 44분) 처리했고, turbo와 large-v3는 실시간보다 느리다.
- **반복·환각이 모델 전반에 나타난다.** base(한 줄 904회)와 turbo(918회)가 가장 심하고 small도 107회다. 이 경우 base의 빠른 속도(8.3초/분)는 반복 출력 때문에 짧아졌을 수 있어 속도 수치를 그대로 신뢰할 수 없다. medium은 최대 12회, large-v3는 36회로 상대적으로 적다.
- 반복이 적은 모델이 medium(12), large-v3(36)이다. 샘플 02에서 medium은 반복이 없었다. 샘플·모델마다 반복 정도가 달라 **반복의 원인은 샘플 내용(무음·잡음 구간)과 모델의 조합으로 보이며**, 시험 중 CPU 부하와는 관련이 없는 것으로 판단한다. 근거: 같은 조건 반복 시 전사문 해시가 동일(base·small 샘플 01·02 전부), 두 PC에서 같은 세그먼트 수. 단 medium 이상은 반복 실행으로 직접 확인하지 않았다.
- 반복 억제 옵션(VAD, `--max-context 0` 등)은 사용하지 않았다. 효과는 후속 시험 대상이다.

## 3. 해석

- 이 PC(8스레드, CPU 전용)에서 medium 이상은 **실시간보다 느리다**. 1시간 회의 환산: medium 약 48~52분, turbo 약 60~67분, large-v3 약 85~130분. 한 회의를 끝낼 때까지 CPU를 점유하므로 백그라운드 처리 전제가 필요하다.
- 소요는 base < small < medium < turbo < large-v3 순이다. turbo는 이름과 달리 medium보다 느렸다(이 CPU·이 빌드 기준, 원인 미검증).
- large-v3의 1분당 시간이 샘플 01(130)과 02(85)에서 크게 다르다. 단일 측정이며 짧은 샘플의 고정 비용이나 열 상태 영향 가능성이 있어 결론을 내리지 않는다.
- 최대 RAM은 최대 2.25 GB로 16 GB 기기에서 문제없다.
- **turbo 반복 루프 확인(2026-11-03):** 샘플 02 전사문을 내용 출력 없이 통계만 계산한 결과, turbo는 729줄 중 고유 326줄이고 한 줄이 **396번** 반복되었다. medium은 171줄 모두 고유, large-v3는 245줄 중 고유 211줄(최대 반복 35). turbo의 반복은 환각·루프 현상으로 보이며, 속도 수치는 이 반복 출력을 포함한다. 원인(무음 구간, 옵션 등)과 large-v3의 반복은 미검증이며 품질 평가 때 확인한다. 이후 측정 기록에는 `uniqueSegmentCount`, `maxRepeatedSegmentCount`가 함께 저장된다.
- **품질은 평가하지 않았다**(기준 전사본·동의 미확보, `quality=null`). 세그먼트 수로 품질을 판단하지 않는다.

## 4. 잠정 판단과 마무리 결정 (2026-11-03)

- 속도만으로는 `small`이 기본값 후보로 보이나, 반복·환각이 모델 전반에 나타나므로(§2-1) 속도 수치만으로 결정하지 않는다.
- **시스템 부하 영향 시험은 하지 않기로 결정했다.** 같은 조건 재실행 시 전사문 해시가 동일했고(base·small), 두 PC에서 세그먼트 수가 같았으며, 같은 환경에서 모델별 반복 정도가 달랐다. 따라서 전사 결과 차이는 시스템 부하가 아니라 모델·샘플 조합에서 온다고 판단한다. 추가 부하 시험은 실시하지 않는다.
- **모델 선정은 결과 육안 검증 후 결정한다.** 처리율·메모리·반복 통계만으로는 전사 품질을 판단할 수 없으므로, 각 모델의 전사 결과를 사람이 직접 확인한 뒤 기본 모델과 선택 옵션을 정한다. 계획은 TODO `0-BASE-08`에 둔다.
- Samsung의 whisper.cpp 모델 측정(base, small, medium, large-v3-turbo, large-v3; 샘플 01~03)은 이것으로 마무리한다. Lenovo의 medium 이상 측정은 진행할 예정이며(TODO 0-BASE-06 후속 ②), 결과는 [1시간 회의 소요 집계표](./BASE-09_ONE_HOUR_MEETING_TIME_2026-11-03.md)에 반영한다.
- 1시간 회의의 허용 처리 시간 목표는 아직 정해지지 않았다.

### 5-2. 분석 및 발견사항
1. **세그먼트 수 100% 일치**: 5개 전 모델에서 두 기기의 세그먼트 수가 완벽히 일치하여 CPU 아키텍처(13세대 i5 vs 10세대 i7) 차이에도 불구하고 추론 결정론성(determinism)이 보장됨을 확인했다.
2. **처리율 비교**: 최신 아키텍처인 Samsung i5-1340P가 Lenovo i7-10750H 대비 전반적으로 8%~40% 빠른 처리율을 보인다. 특히 `medium` 모델의 경우 Lenovo(55.3초/분)와 Samsung(51.3초/분)의 차이가 약 8%로 가장 적다.
3. **메모리(RAM)**: 최대 메모리 사용량은 `medium` 약 1.25 GB, `turbo` 약 0.93 GB, `large-v3` 약 2.13 GB로 두 기기 간 차이가 없으며 16 GB 시스템에서 안정적으로 동작한다.
4. **반복 통계**: `real-sample-01`에서는 5개 모델 모두 `maxRepeatedSegmentCount = 1`로 반복/환각 루프가 전혀 나타나지 않았다.
