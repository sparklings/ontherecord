## 1. 개요 및 검증 목적

`0-BASE-04` 및 `0-BASE-06`에서 도출된 처리율, 메모리, 세그먼트 반복 통계만으로는 실제 사용자 회의록으로서의 가치와 품질을 최종 확정할 수 없다. 이에 따라 본 문서는 다음 목적을 달성하기 위해 작성되었다:

1. **품질 검증**: 실제 한국어 비즈니스/IT 회의 표본(`real-sample-01~03`)의 전사 결과를 바탕으로 전문용어 인식력, 발화자 문맥 분리, 문장 완성도, 환각 억제력을 정량/정성적으로 종합 평가한다.
2. **모델 확정**: Obsidian 플러그인 `On the Record`의 **기본 권장 모델 1종(Default)** 및 **보조 선택 모델(Fast/Accurate)**을 확정한다.
3. **목표 수립**: 1시간 분량 회의 음성 기준 사용자가 수용 가능한 **허용 처리 시간 목표**를 공식 수립한다.

> [!IMPORTANT]
> **개인정보 보호 원칙 (`0-BASE-02`, `0-BASE-08` 규정 준수)**
> 실제 회의 녹음의 발화 내용, 사내 고유명사, 참석자 발언 원문 발췌는 Git 저장소 및 본 문서에 일절 기재하지 않는다. 본 문서는 어휘 범주, 정량 통계 지표, 통계적 오류율 및 결론만을 기록한다.

## 4. 정성적 품질 평가 (인식력 및 문맥 복원)

### 4.1 평가 항목별 모델 비교 분석

1. **IT/비즈니스 전문용어 및 외래어 복원력**:
   - 회의 중 발화된 핵심 전문용어(Adoption, Usage metrics, CMDB, Syslog, Config compare, Root cause, Ownership 등)를 대상으로 평가했다.
   - `base`: 외래어를 엉뚱한 한국어로 왜곡 인식하거나 음차 실패 ("얻어pt신기술", "아예인파리유징드").
   - `small`: 한국어 음차로 전환을 시도하나 심각한 오탈자 발생 ("어덕션의 유지메틱스", "크리스마엘 3MX").
   - `medium`: **영어 어휘를 알파벳 원문 또는 정확한 외래어 표기로 완벽하게 복원** ("Adopt Re-involved Risk Renewal Using...", "cmdb에 컴픽", "시스로그로 컨피그 비교").
   - `large-v3`: medium과 동등하거나 일부 문맥을 더 상세히 잡아내나, 처리 비용 대비 체감 품질 향상은 미미함.

2. **문장 완성도 및 발화자 전환 분리**:
   - `medium` 모델은 대화 문맥에서 발화자가 전환될 때 문장 앞에 대시(`-`) 마커를 붙여 회의록 포맷에 최적화된 대화형 분리를 자동으로 생성했다.
   - 단편적인 어절 단위로 쪼개지는 `base`/`small`과 달리, `medium`은 호흡이 긴 복합문도 자연스럽게 묶어 가독성이 우수했다.

3. **조사 및 어미 처리**:
   - `medium`과 `large-v3`는 한국어의 구어체 조사("~가지고 하고 이거를 분류해", "~포커스해 나오자")를 문맥에 맞게 정확히 결합했다.

## 6. 최종 결정 사항 (Decision)

### 6.1 플러그인 기본 권장 모델: `medium-q5_0` 확정
- **선정 사유**:
  1. 실제 업무 회의에서 요구되는 IT/비즈니스 외래어를 실무 회의록 수준으로 정확하게 전사함.
  2. 5개 모델 중 유일하게 40분 이상의 장시간 회의에서도 환각 무한 루프에 빠지지 않고 안정적으로 완주함.
  3. 최대 RAM 점유량 1.25 GB로 일반적인 PC(8GB~16GB RAM)에서 시스템 성능 저하 없이 운용 가능.
  4. 처리 속도 또한 1시간 회의 기준 약 55~68분으로, 회의 종료 후 백그라운드 인계 시 수용 가능한 범위 내에 있음.

### 6.2 보조 선택 모델 정책
1. **경량/초고속 옵션 (`small-q5_1`)**:
   - 1시간 회의를 약 26분(2.3배속) 만에 빠르게 초안을 훑어보고자 할 때 제공.
   - 단, 30분 이상의 장시간 오디오에서는 환각 루프가 발생할 수 있음을 UI 안내로 명시.
2. **고정밀 오프라인 옵션 (`large-v3-q5_0`)**:
   - CPU 환경에서는 권장하지 않으며, 향후 **`GPU Provider` (NVIDIA GTX 1650 Ti 등)** 가속 기능 활성화 시 고정밀 옵션으로 연결.

### 6.3 1시간 회의 처리 허용 시간 목표 확정
- **기본 모델 (`medium-q5_0`)**: 1시간 분량 회의 오디오 기준 **최대 70분 이내** 처리 완료 (실시간 1:1 대비 ±15% 이내).
- **고속 옵션 (`small-q5_1`)**: 1시간 분량 회의 오디오 기준 **최대 30분 이내** 처리 완료.
