# 5. 프라이버시 원칙 및 시스템 아키텍처 (Architecture & Privacy)

On the Record는 기업 및 개인의 최고 수준 보안 요구사항을 충족하도록 설계되었습니다.

---

## 🔒 100% 로컬 오프라인 무전송 보장 (Zero Cloud Leaks)

- **순수 로컬 프로세스**:
  - 오디오 정규화(`ffmpeg.exe`) 및 음성 인식 추론(`whisper-cli.exe`)은 전적으로 사용자의 로컬 CPU와 GPU에서만 독립 실행됩니다.
  - 외부 클라우드 API(OpenAI, Google, AWS 등)와의 네트워크 소켓 연결이 코드베이스 레벨에서 원천 배제되어 있습니다.
- **오프라인 동작**:
  - 인터넷이 완전히 차단된 에어갭(Air-Gapped) 망 또는 비행기 모드에서도 100% 동일하게 모든 기능이 정상 동작합니다.
- **음성 녹음 파일 및 전사문 외부 유출 원천 금지 (Zero-Leakage Policy)**:
  - 실제 음성 파일 및 전사 텍스트는 로컬 Vault 및 로컬 스토리지에만 저장되며 외부 전송이 원천 금지됩니다.
  - 개발, 디버깅, 벤치마크 수행 시에도 터미널 콘솔이나 리포트에 실제 발화 내용 원문을 절대 출력하지 않으며, 집계 메트릭(소요시간, RAM, 세그먼트 수)만 처리합니다.

## 📊 외부 공개 표준 음성 표본 샘플링 체계 (Benchmark Dataset)

민감한 실제 회의 음원을 안전하게 보호하면서도 일관되고 재현 가능한 벤치마크 및 회귀 테스트를 수행하기 위해 다음과 같은 다구간 표준 샘플링 체계를 수립합니다:

- **데이터 확보 원칙**: 개인 녹음 대신 외부 공개 데이터셋(AI Hub 오픈데이터, CC 라이선스 표준 음원 등)을 활용.
- **표준 샘플링 구간 (5단계)**:
  1. **1분 (Quick Test)**: 신속한 기능 정상성 및 런타임 링크 검증
  2. **5분 (Short Meeting)**: 일상 스크럼, 짧은 업무 싱크 검증
  3. **10분 (Standard Sprint)**: 표준 스프린트 및 중간 분량 전사 정합성
  4. **30분 (In-depth Session)**: 중간 길이 회의 및 세그먼트 누적 메모리 검증
  5. **60분 (Full Meeting)**: 1시간 장시간 회의 완주력 및 환각(Hallucination) 루프 억제력 검증

## 🌐 한영 혼용(Code-switching) 및 IT 전문용어 인식 전략

실제 한국어 비즈니스 및 엔지니어링 회의에서는 영어 단어, 약어 및 고유명사(API, PR, Obsidian, Jira, Docker, Sprint, LLM, Git 등)가 빈번하게 혼용됩니다.

- **발음 음차 왜곡 방지**: 모델이 외래어를 억지 한글 음차(예: "오비시디언", "에이피아이")로 변환하거나 오인식하지 않도록 유도.
- **Whisper 초기 어휘 프롬프팅(Vocabulary Prompting)**: whisper.cpp의 `--prompt` 및 `--carry-initial-prompt` 옵션을 통해 사전에 정의된 도메인 전문용어 및 사용자가 등록한 고유명사 힌트를 디코더에 주입하여 혼용 발화 인식률을 극대화합니다.

## 🧩 단일 세션 모델 및 마커 격리 아키텍처

- **단일 활성 세션 (`RecordingSessionManager`)**:
  - 동시 다발적인 녹음 충돌을 방지하기 위해 엄격한 단일 세션 모델을 채택합니다.
  - 비정상 종료 시에도 디스크 영속 파일(`active-session.json`)을 통해 앱 재시작 시 안전하게 복구합니다.
- **세션 마커 기반 마크다운 격리**:
  - 하나의 문서에 여러 번 녹음이 누적될 때 각 세션을 고유 마커로 감쌉니다:
    ```markdown
    <!-- on-the-record:start audio="Recording 20261119.m4a" seq="1" -->
    [00:00] 안녕하세요, 오늘 회의를 시작하겠습니다.
    <!-- on-the-record:end audio="Recording 20261119.m4a" seq="1" -->
    ```
  - 재전사를 수행하더라도 해당 세션 블록만 정밀하게 교체되며, 사용자가 작성한 다른 필기와 노트는 안전하게 보존됩니다.
