# 5. 프라이버시 원칙 및 시스템 아키텍처 (Architecture & Privacy)

On the Record는 기업 및 개인의 최고 수준 보안 요구사항을 충족하도록 설계되었습니다.

---

## 🔒 100% 로컬 오프라인 무전송 보장 (Zero Cloud Leaks)

- **순수 로컬 프로세스**:
  - 오디오 정규화(`ffmpeg.exe`) 및 음성 인식 추론(`whisper-cli.exe`)은 전적으로 사용자의 로컬 CPU와 GPU에서만 독립 실행됩니다.
  - 외부 클라우드 API(OpenAI, Google, AWS 등)와의 네트워크 소켓 연결이 코드베이스 레벨에서 원천 배제되어 있습니다.
- **오프라인 동작**:
  - 인터넷이 완전히 차단된 에어갭(Air-Gapped) 망 또는 비행기 모드에서도 100% 동일하게 모든 기능이 정상 동작합니다.

---

## 🧩 단일 세션 모델 및 마커 격리 아키텍처

- **단일 활성 세션 (`RecordingSessionManager`)**:
  - 동시 다발적인 녹음 충돌을 방지하기 위해 엄격한 단일 세션 모델을 채택합니다.
  - 비정상 종료 시에도 디스크 영속 파일(`active-session.json`)을 통해 앱 재시작 시 안전하게 복구합니다.
- **세션 마커 기반 마크다운 격리**:
  - 하나의 문서에 여러 번 녹음이 누적될 때 각 세션을 고유 마커로 감쌉니다:
    ```markdown
    <!-- on-the-record:start audio="Recording 20261119.m4a" seq="1" -->
    [00:00] 안녕하세요, 오늘 회의를 시작하겠습니다.
    <!-- on-the-record:end audio="Recording 20261119.m4a" seq="1" -->
    ```
  - 재전사를 수행하더라도 해당 세션 블록만 정밀하게 교체되며, 사용자가 작성한 다른 필기와 노트는 안전하게 보존됩니다.
