# 3. 환경 설정 종합 레퍼런스 (Settings Reference)

On the Record의 모든 설정 옵션에 대한 상세 레퍼런스입니다.  
설정 화면 최상단의 [📖 상세 설정 가이드 보기]를 통해서도 확인하실 수 있습니다.

---

## 1. 음성 녹음 및 회의록 세션

- **회의록 작성 시 녹음 시작 방식 (`recordStartMode`)**:
  - `새 회의록 작성 시 자동 시작 (권장)`: 새 문서를 열면 즉시 코어 레코더를 켭니다.
  - `단축키 또는 버튼으로 수동 시작`: 사용자가 명시적 명령을 실행할 때만 켭니다.
- **녹음 시작 안내 알림 표시 (`recordStartNotification`)**:
  - 자동 시작 시 우측 상단 토스트 팝업 표시 여부입니다. (꺼도 하단 상태표시줄 타이머는 항상 표시)
- **회의록 마크다운 노트 보관 폴더 (`autoRecordFolder`)**:
  - 지정한 폴더 내의 새 문서에만 자동 녹음 규칙을 적용합니다. (비워두면 볼트 전체)
- **작성 중인 노트 탭을 닫을 때 (`onTabCloseAction`)**:
  - `녹음 안전 중지 및 오디오 자동 연결 (권장)`: 실수로 탭을 닫아도 파일 유실 없이 안전 저장.
  - `녹음 유지`: 수동으로 중지할 때까지 계속 녹음.

---

## 2. 음성 전사 파이프라인

- **녹음 종료 즉시 백그라운드 전사 시작 (`autoTranscribe`)**:
  - 녹음이 끝나면 멈춤 현상 없이 비동기 백그라운드 큐로 자동 인계합니다.
- **외부 음성 파일 자동 감지 (`autoDetectRecording`)**:
  - 스마트폰 녹음기나 외부 오디오 파일 유입 시 자동 전사 대기열에 등록합니다.
- **전사 결과 노트 반영 방식 (`transcriptionInsertMode`)**:
  - `오디오 임베드 아래 자동 삽입 (권장)` / `미리보기 모달 검토 후 승인 삽입`
- **오디오 저장 완료 대기 시간 (초) (`stabilizationSeconds`)**:
  - 녹음기나 동기화 도구가 파일 쓰기를 완전히 마칠 때까지 기다리는 시간 (기본값: 5초).
- **기본 전사 언어 (`language`)**:
  - `한국어(ko)` (권장) / `다국어 자동 감지(auto)` / `영어(en)`
- **음성인식 모델 크기 (`defaultModelSize`)**:
  - `Medium` (기본 권장) / `Small` / `Base` / `Large-v3-Turbo` / `Large-v3`
- **맞춤형 어휘 힌트 (`vocabularyPrompt`)**:
  - 한영 혼용 IT 전문용어 및 고유명사를 쉼표로 구분해 등록하면 `whisper-cli --prompt` 인자로 전달됩니다.
- **연산 프로세서 선호도 (`devicePreference`)**:
  - `자동 선택` / `GPU 가속기 우선` / `CPU 전용`

---

## 3. 이 기기의 전사 도구 경로 및 상태 (`이 PC 전용`)

- **도구 준비 상태 배너**: `전사 & 모델` 탭 상단에서 `FFmpeg`, `whisper-cli`, `Model`의 준비 여부를 확인하고 `1-클릭 셋업` 명령어를 복사할 수 있습니다.
- **런타임 실행 파일 (`runtimePath`)**: `whisper-cli.exe` 절대 경로 (`[찾아보기]` 선택 가능)
- **모델 파일 (`modelPath`)**: `ggml-*.bin` 모델 절대 경로 (`[찾아보기]` 선택 가능)
- **FFmpeg 실행 파일 (`ffmpegPath`)**: `ffmpeg.exe` 절대 경로 (`[찾아보기]` 선택 가능)
- **로컬 AI 회의록 요약 (`enableLocalLlm`, `localLlmEndpoint`, `localLlmModel`)**:
  - `localhost` / `127.0.0.1` 전용 Ollama 및 OpenAI 호환 서버 연동 설정

*(참고: 설정 화면은 `워크플로`, `전사 & 모델`, `가속 & AI` 3단 탭으로 구성되며, 각 섹션에 `Vault 동기화` 또는 `이 PC 전용` 범위 배지가 표시됩니다.)*
