# 용어집 (GLOSSARY)

프로젝트에서 사용하는 용어의 정의를 기록한다. 사용자와 작업자(Copilot)가 같은 의미로 말하기 위한 문서이다.

## 작성 규칙

- 이해하지 못한 기술 용어나 의미가 어긋난 용어는 발견한 시점에 항목을 추가한다.
- 항목은 가나다순으로 정렬한다. 영문 용어는 한글 표제어 옆에 병기한다.
- 정의는 이 프로젝트에서 쓰는 의미로 적는다. 일반적인 의미와 다르면 그 차이를 적는다.
- 각 항목에 작성일을 적는다. 정의가 바뀌면 이전 정의를 지우지 않고 변경 일자와 변경 내용을 `변경 이력`에 남긴다.
- 관련 문서의 위치를 함께 적는다.

## 항목

### provider (프로바이더)

**작성일:** 2026-11-01 / **변경 이력:** 없음

**정의:** 전사를 실제로 수행하는 실행 단위. 플러그인 본체와 전사 엔진 사이에 놓이며, 엔진별 차이(실행 파일, 장치, 입출력 방식)를 안에 감춘다.

**이 프로젝트의 예**

| provider | 엔진 | 실행 장치 | 단계 |
|---|---|---|---|
| `whisper.cpp` CPU | `whisper.cpp` | CPU | 2단계 |
| `whisper.cpp` CUDA | `whisper.cpp` | NVIDIA GPU | 3단계(검증 후 결정) |
| `whisper.cpp` OpenVINO | `whisper.cpp` | Intel GPU | 3단계(검증 후 결정) |

**특징**
- 플러그인은 provider의 종류를 구분하지 않고 같은 방식으로 호출한다.
- provider를 추가해도 설정 화면, 결과 미리보기, 노트 삽입 코드는 바뀌지 않는 것을 목표로 한다.
- 장치가 감지되었다는 사실만으로 provider를 사용 가능으로 표시하지 않는다. 설치와 시험 추론이 성공해야 사용 가능이다.
- 일반 용어 "provider(제공자)"와 달리, 이 프로젝트에서는 클라우드 서비스 제공자를 뜻하지 않는다. 모든 provider는 사용자 PC에서 실행된다.

**관련 문서:** 개발계획서 §5~§6

### provider 계약 (provider contract)

**작성일:** 2026-11-01 / **변경 이력:** 2026-11-05 `src/provider.ts`에 공통 TypeScript 계약 추가

**정의:** provider와 플러그인 본체가 주고받는 입력·출력의 규칙을 미리 정의한 인터페이스. 코드에서는 TypeScript 인터페이스와 데이터 형식으로 나타난다. 엔진을 구현하는 작업이 아니라 규칙을 정하는 작업이다.

**포함 내용**
1. 자기 보고: 식별자, 버전, 라이선스, 지원 OS·CPU 아키텍처, 입력 형식, 실행 장치, 외부 요구사항 및 준비 상태
2. 요청·제어: 오디오와 모델 경로, 언어·장치 설정, `AbortSignal`, 진행 콜백
3. 결과: 언어, 전체 텍스트, 초 단위 segment 시작·끝 시각과 텍스트, provider·모델·실행 장치, 경고
4. 오류: provider 식별자와 공통 오류 코드. 취소는 성공 결과로 표현하지 않음

**구현 범위:** 계약 타입만 정의했으며, 실제 엔진·provider registry·worker는 구현하지 않았다. 후속 단계에서 mock provider로 계약을 검증한다.

**관련 문서:** [provider.ts](../../src/provider.ts), 개발계획서 §6 "provider 공통 계약"

### provider manifest (프로바이더 매니페스트)

**작성일:** 2026-11-01 / **변경 이력:** 없음

**정의:** 설치 가능한 provider·런타임·모델의 목록과 조건을 적은 파일. 버전, 지원 Windows 버전·CPU 아키텍처, 필요한 드라이버, 다운로드 주소, SHA-256 해시, 파일 크기를 담는다. 프로젝트가 검증한 항목만 등록한다.

**관련 문서:** 개발계획서 §7, §10

### segment (세그먼트)

**작성일:** 2026-11-01 / **변경 이력:** 없음

**정의:** `whisper.cpp`가 전사 결과를 나누는 발화 구간 단위. 시작·끝 시각과 텍스트를 가진다. 단어 단위가 아니다.

**주의:** 첫 구현의 timestamp는 segment 단위이다. 단어 내부의 시작·끝 시각은 별도 정렬 모델을 검증하기 전에는 제공하지 않는다.

**관련 문서:** 개발계획서 §1, §8

### 가속기 (accelerator)

**작성일:** 2026-11-01 / **변경 이력:** 없음

**정의:** CPU 대신 전사 연산을 수행하는 하드웨어. 이 프로젝트에서는 NVIDIA GeForce GTX(CUDA)와 Intel 내장 GPU(Iris Xe, UHD Graphics)를 후보로 본다. 사용 여부는 실제 시험 추론 성공으로 판단한다.

**관련 문서:** 개발계획서 §4~§5
