# On the Record 설정 상세 가이드 (Settings Guide)

이 문서는 **On the Record (옵시디언 로컬 음성 회의록 플러그인)**의 모든 설정 옵션에 대한 상세 가이드입니다.  
각 옵션이 **왜 필요한지**, **어떻게 설정해야 하는지**, 그리고 **설정했을 때 어떤 성능·안정성 개선 효과가 있는지**를 안내합니다.

---

## 1. 설정 저장 구조 이해

On the Record는 사용자의 프라이버시와 기기 간 독립성을 위해 설정을 두 계층으로 완전히 분리하여 관리합니다:

1. **볼트 공통 설정 (`data.json`)**:
   - 녹음 시작 방식, 전사 언어, 자동 전사 여부 등 **어느 기기에서든 동일하게 적용될 사용자 정책**입니다.
   - Obsidian Sync 또는 클라우드(OneDrive, iCloud, Git 등)로 안전하게 동기화됩니다.
2. **기기별 로컬 설정 (`local-settings.json`)**:
   - 실행 파일 경로(`whisper-cli.exe`, `ffmpeg.exe`), 모델 파일 위치, GPU 가속 백엔드 등 **해당 PC의 하드웨어 스펙에 종속적인 설정**입니다.
   - 기기별 로컬 폴더(`%LOCALAPPDATA%\on-the-record\local-settings.json`)에만 격리 보관되며, 다른 PC로 동기화되어 충돌을 일으키지 않습니다.

## 2. 음성 녹음 및 세션 설정

### 2.1. 녹음 시작 방식 (`recordStartMode`)
- **옵션**:
  - `자동 시작 (새 노트 생성 시 즉시 녹음)` (기본값)
  - `수동 시작 (자동 시작 안 함)`
- **왜 필요한가?**:
  - 회의가 시작되어 새 문서를 열었을 때 녹음 버튼을 누르는 것을 잊어 회의 초반 음성을 놓치는 사고를 원천 방지합니다.
- **개선 및 권장 사항**:
  - 회의록 전용 볼트나 회의록 폴더를 사용하는 경우 `자동 시작`을 권장합니다.
  - 일상 메모나 독서 노트 등 다양한 문서를 함께 작성하는 볼트라면 아래 **2.3 대상 폴더**를 지정하거나 `수동 시작`으로 설정하고 단축키를 사용하는 것이 좋습니다.

### 2.2. 자동 시작 시 알림 표시 (`recordStartNotification`)
- **옵션**: `켜기(기본값)` / `끄기`
- **왜 필요한가?**:
  - 새 노트가 열리면서 백그라운드에서 녹음이 시작되었는지 시각적으로 즉각 피드백을 제공합니다.
- **개선 효과**:
  - 불필요한 팝업을 원치 않고 조용히 작성하고 싶다면 끄기를 선택할 수 있습니다. (상태표시줄에 실시간 빨간색 녹음 타이머 `🔴 01:23`는 항상 표시됩니다.)

### 2.3. 녹음 자동 시작 대상 폴더 (`autoRecordFolder`)
- **입력 예시**: `Meetings`, `회의록`, `01_Projects/Meetings`
- **왜 필요한가?**:
  - 볼트 내의 아무 노트나 생성할 때마다 녹음이 시작되는 부작용을 방지합니다.
- **개선 효과**:
  - 지정한 폴더 내에서 생성되는 마크다운 노트에만 녹음 라이프사이클이 연동되어, 일반 작업 노트 작성을 전혀 방해하지 않습니다.

### 2.4. 노트 탭 닫힘 시 동작 (`onTabCloseAction`)
- **옵션**:
  - `녹음 자동 중지 및 오디오 안전 연결 (권장)` (기본값)
  - `녹음 유지 (수동 중지)`
- **왜 필요한가?**:
  - Obsidian에서 회의 중 실수로 노트 탭(`Ctrl + W`)을 닫아버렸을 때, 녹음이 계속 돌거나 오디오 파일이 노트에 연결되지 않는 **고아(미아) 파일 발생 사고**를 완벽하게 차단합니다.
- **개선 효과**:
  - 탭이 닫히는 즉시 백그라운드에서 녹음을 정상 중지하고, 해당 노트 본문에 오디오 임베드를 안전하게 저장합니다.

## 3. 음성 전사 파이프라인 설정

### 3.1. 자동 전사 (`autoTranscribe`)
- **옵션**: `켜기(기본값)` / `끄기`
- **왜 필요한가?**:
  - 녹음이 끝나면 사용자가 일일이 메뉴를 눌러 전사를 돌릴 필요 없이, 비차단 백그라운드 전사 큐(`TranscriptionQueueWorker`)로 자동 인계합니다.
- **개선 효과**:
  - 전사가 진행되는 동안(10분~30분) 사용자는 멈춤(Freeze) 현상 없이 Obsidian에서 다른 메모를 자유롭게 작성할 수 있습니다.

### 3.2. 전사 결과 반영 방식 (`transcriptionInsertMode`)
- **옵션**:
  - `오디오 임베드 아래 자동 삽입 (권장)` (기본값)
  - `미리보기 모달로 검토 후 승인 삽입`
- **설정 효과**:
  - **자동 삽입**: 백그라운드 전사가 완료되면 대상 노트의 해당 녹음 위치 바로 아래에 마크다운 블록으로 조용히 결과를 자동 기재합니다.
  - **검토 후 삽입**: 전사 완료 시 알림 팝업이 뜨며, 모달 창에서 문장을 직접 눈으로 확인·수정한 뒤 노트를 업데이트합니다.

### 3.3. 파일 안정화 대기 시간 (`stabilizationSeconds`)
- **기본값**: `5초` (범위: 1~60초)
- **왜 필요한가?**:
  - 녹음기가 오디오 파일 쓰기(Flushing)를 완전히 끝마치기 전에 전사 엔진이 파일을 읽으려 하면 파일 손상 오류가 발생합니다.
- **개선 효과**:
  - 지정된 시간 동안 파일 크기와 수정 시간이 멈춰 완전히 저장되었음을 확인한 뒤 전사 엔진으로 넘깁니다.

### 3.4. 언어 (`language`)
- **옵션**: `한국어(ko)` (권장), `자동(auto)`, `영어(en)`
- **개선 효과**:
  - 한국어 회의록의 경우 `ko`로 명시하면, 초반 무음 구간이나 잡음 구간에서 모델이 영어나 일본어로 엉뚱하게 언어를 오인(Hallucination)하는 문제를 원천 방지합니다.

### 3.5. 기본 모델 크기 (`defaultModelSize`)
- **지원 모델 (GGML 양자화)**: `base`, `small`, `medium` (기본 권장), `large-v3-turbo`, `large-v3`
- **비교 및 가이드**:
  | 모델 크기 | 양자화 | 모델 파일 크기 | 1시간 회의 소요 시간 (CPU) | 한국어 전문용어 품질 | 권장 환경 |
  | :--- | :--- | :--- | :--- | :--- | :--- |
  | **`base`** | `q5_1` | 148 MB | 약 8 ~ 15분 | 일상 대화 가능 / 전문용어 오인 | 저사양 PC, 고속 전사 |
  | **`small`** | `q5_1` | 466 MB | 약 12 ~ 26분 | 중간 수준 / 조사 정확도 양호 | 일반 노트북 작업 |
  | **`medium`** | `q5_0` | 514 MB | 약 44 ~ 68분 | 우수 (IT/비즈니스 전문용어 복원·환각 억제) | 공식 권장 표준 모델 |
  | **`large-v3-turbo`** | `q5_0` | 547 MB | 약 60 ~ 83분 | 경량 4-디코더 고속·고정밀 | 중급 이상 PC |
  | **`large-v3`** | `q5_0` | 1,031 MB | 약 110 ~ 171분 | 최상 (다국어 혼용, 방언) | 외장 GPU(CUDA) 환경 |

### 3.6. 맞춤형 어휘 힌트 (`vocabularyPrompt`)
- **역할**: `whisper-cli` 실행 시 `--prompt` 인자로 전달되어 한국어 대화 중 섞이는 영문 IT 용어(`API`, `Obsidian`, `Docker`, `TypeScript` 등)나 고유명사의 한글 음차 오인을 줄입니다.

## 4. 하드웨어 및 GPU 가속 설정

외장 GPU(NVIDIA) 또는 최신 내장 GPU(Intel Iris Xe)를 활용하여 CPU 발열과 소음을 줄이고 전사 속도를 가속합니다.

### 4.1. GPU 가속 백엔드 (`gpuBackend`)
- **옵션**:
  - `자동 감지 (Auto)` (기본값)
  - `NVIDIA CUDA (외장 GPU)`: GeForce GTX / RTX 외장 그래픽이 장착된 노트북/데스크톱
  - `Vulkan (Intel Iris Xe / AMD / NVIDIA)`: 인텔 내장 그래픽 또는 AMD 그래픽에서 시스템 기본 Vulkan 드라이버 사용
  - `CPU 전용 (CPU)`: GPU 가속을 완전히 끄고 안정적인 CPU 멀티스레드로 구동

### 4.2. GPU 오프로드 레이어 수 (`-ngl`, `gpuLayers`)
- **기본값**: `0` (CPU 전용) / **권장값**: `99` (GPU 완전 오프로드)
- **왜 설정해야 하는가?**:
  - Whisper 신경망의 트랜스포머 인코더/디코더 레이어들을 GPU 전용 메모리(VRAM)로 옮겨 연산합니다.
- **설정 시 개선 효과**:
  1. **CPU 점유율 급감**: CPU 코어가 100% 점유되어 노트북 쿨링 팬이 굉음을 내며 뜨거워지는 현상을 완전히 방지합니다.
  2. **추론 속도 2배~4배 가속**: 1시간 분량 회의 전사 시 `medium` 모델 기준 처리 시간이 10~15분 안팎으로 대폭 단축됩니다.
  3. **VRAM 4GB 환경 최적화**: VRAM 4GB(예: GTX 1650 Ti) 환경에서도 `base`, `small`, `medium` 모델 전체를 100% VRAM에 적재(`-ngl 99`)할 수 있습니다.

### 4.3. GPU 장치 번호 (`gpuDeviceId`)
- **기본값**: `0`
- 내장 그래픽과 외장 그래픽이 모두 장착된 듀얼 GPU 노트북에서, 외장 그래픽을 우선 타겟팅할 때 인덱스(0 또는 1)를 지정합니다.

## 5. 전사 도구 경로 및 상태 확인

설정 화면의 **이 기기의 음성 전사 도구 경로 및 상태** 영역은 외부 도구의 무결성을 실시간 점검합니다:

- **런타임 실행 파일 (`runtimePath`)**: `whisper-cli.exe`의 전체 절대 경로입니다.
- **모델 파일 (`modelPath`)**: `ggml-base-q5_1.bin` 또는 `ggml-medium-q5_0.bin` 모델 경로입니다.
- **FFmpeg 실행 파일 (`ffmpegPath`)**: 오디오를 16 kHz 모노 PCM WAV 규격으로 손실 없이 정규화하는 `ffmpeg.exe` 경로입니다.

### 세련된 상태 뱃지 안내
- **`● 준비됨 · 142.5 MB` (부드러운 녹색 알약)**: 파일이 올바른 위치에 정상 존재하며 플러그인이 즉시 실행할 수 있는 상태입니다.
- **`● 파일 없음` (부드러운 적색 알약)**: 지정된 경로에 파일이 없거나 읽기 권한이 없습니다. 파일 경로를 다시 확인하거나 아래 자동 셋업 스크립트를 실행하세요.

## 6. 외부 도구 원클릭 자동 셋업 스크립트

수동으로 도구를 다운로드하고 경로를 맞추기 번거로운 사용자를 위해 독립 실행형 자동화 스크립트를 제공합니다:

1. 설정 화면 하단의 **[명령어 복사]** 버튼을 클릭합니다.
2. Windows의 **PowerShell** 창을 열고 `Ctrl + V` 후 Enter를 누릅니다.
3. 스크립트가 공식 검증된 whisper.cpp, 기본 모델, FFmpeg를 다운로드하여 사용자 로컬 폴더에 배치하고, `local-settings.json`까지 원클릭으로 완벽하게 구성합니다.
